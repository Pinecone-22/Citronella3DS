Welcome to Citronella3DS!

Citronella is a W.I.P. visual novel (VN) engine for the Nintendo 3DS, built for speed and control.
Features

    Proprietary archive formats: .CVN for visual novels and .CVNM for mods.

    Easy porting: Bring existing Python/Ren'Py novels over to Citronella

    In-game overlay: Aimed at developers and tech-savvy users, allowing in-depth VN modification, FPS counters, metrics, and logs.

    Mod loader: Apply mods at runtime.

    CLI Python tool: Converts Ren'Py novels to C++ (WIP; tested on DDLC and two other novels).

    Cool and modern UI.
